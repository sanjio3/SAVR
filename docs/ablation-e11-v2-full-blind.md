# E11 消融（v2 全盲化）：布局依赖从 15.2pp 降到 8.9pp

> 口径：文中的三位数是运行轮次标签，用于区分对照组，与工程流程编号无关。
**日期**：2026-10-27　**对照**：473（常规布局+先验开）／474（v1 盲测+先验关）／479（v2 盲测+先验关）

## 一、结论

v2 变体（路由 / dispatcher 转发 / webapp 目录 / HTML form action 四处全盲化）+
关闭布局先验下，确认态召回 **89.87%**（TP 71/79、FP 0），
较常规布局（98.73%）下降 **8.9pp**。

对比 474 的 v1 盲测（83.54%、TP 66、FP 1）：**召回提高 6.3pp**，
差额主要来自 2026-10-27 落地的 weak_random 静态自证（`static_weak_rng_source` 触发 7 次，
6 条 weak_random TP 全部救回）。

因此更准确的表述是：**当前代码的基准布局依赖约 8.9pp**；15.2pp 是加静态自证之前的数字。

## 五、附带观察

- **A2 耗时方差扩大**：1632s（476）→ 3886s（475）→ 4117s（479），同分片同代码。

- 靶场已恢复常规布局（旧族路由 200 / blind 路由 404 已验证）。

## 六、对外口径建议
