**日期**：2026-10-27　**对照**：473（常规布局+先验开）vs 474（blind 布局+`SAST_AI_BENCHMARK_PRIOR=0`）

且丢失机制可精确定位到「A2 判定层依赖 case#→族先验」。

  case 布局知识（01002/01004 落在 sql 号段）作为判真旁证，盲化后改判。

  774.9s / **gain=0（连续第三轮）**。

  估计偏小，建议校到 40；或把预算降到 150s 逼预检真正拦截。
- 闭环三轮（471 全量/473/474）增益恒 0，**建议默认把 SAST_AI_I2_BUDGET_S 降到 150**，
  闭环定位为廉价安全网，不再指望它提召回。
